# Greedy Tower

### Game Jam Estivale 2026

[Page itch.io](https://itch.io/jam/game-jam-estival/rate/4653250)

Un jeu 3D où vous devez éliminer tous les démons pour gravir la tour. Alternez entre la dimension normale, où vous pouvez vous procurer des armes, et la dimension des démons, où vous affronterez vos ennemis.
